08 Questions

Things people usually ask.

Do I need to know how to code to update my site?

No. I set up the content so that text and images can be changed from one file or one place, and I show you how during the handover.

Will animations slow my website down?

I only animate transform and opacity, which the browser handles efficiently. Animations are kept short and run once.

Can visitors turn animations off?

Yes. Every page checks the reduced-motion setting on the visitor's device and turns animations off when it is set.

Do you provide hosting and a domain?

I can set both up for you, or work with what you already have. Hosting costs are paid directly by you to the provider.
